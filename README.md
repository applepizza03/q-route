# Q-Route: Quantum Logistics Optimizer

Q-Route is an interactive Streamlit app that demonstrates quantum-based global logistics route optimization using QAOA.

## Features

- Global logistics route optimization
- Origin and destination selection
- Scenario-based logistics simulation
- Cost, time, carbon, and risk-based scoring
- QAOA-based quantum route selection
- Classical vs quantum route comparison
- Route visualization on a world map

## How to Run

```bash
streamlit run app.py
